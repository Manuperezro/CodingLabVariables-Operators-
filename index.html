SECTION 3

Input → Process → Output 🔄

Every computer program follows this fundamental 3-step pattern!

1. INPUT
Collect data (e.g. number of tickets)
➔
2. PROCESS
Do calculations (tickets × ticket price)
➔
3. OUTPUT
Display result (show total price)

🎟️ Real Example: Cinema Ticket Machine

Drag or click the code lines below to arrange them into the correct execution order!

☰ total = tickets * price PROCESS
☰ tickets = 3 INPUT DATA
☰ print(total) OUTPUT
☰ price = 8.50 INPUT DATA
💡

Why this order matters:

  • INPUT / DATA: First create tickets = 3 and price = 8.50 so Python knows their values.
  • PROCESS: Calculate total = tickets * price using those variables.
  • OUTPUT: Finally print(total) to display the calculated result on screen.

SECTION 6

The input() Trap ⚠️

This is one of the most common beginner traps in Python programming!

Look at this program carefully:

age = input("How old are you? ")
next_age = age + 1
print(next_age)

WILL THIS PROGRAM WORK? 🤔

How Python processes int(input()) step-by-step:

1 USER TYPES
17
➔
2 input() RETURNS
"17" (String)
➔
3 int() CONVERTS
17 (Integer)
➔
4 CALCULATION
17 + 1
➔
5 OUTPUT
18
✅

The Correct Code:

age = int(input("How old are you? "))
next_age = age + 1
print("Next year you will be", next_age)
SECTION 7

int() or float()? 🔢

Learn when to convert user input into whole numbers (int) versus decimals (float).

When to use each function

int() — Whole Numbers

Use for counting things that cannot be split into fractions (e.g. age, tickets, count).

age = int(input("Age: "))

float() — Decimal Numbers

Use for measurements, prices, weights, and heights that can have decimal points.

price = float(input("Price: £"))

Why must calculations happen after inputs?
